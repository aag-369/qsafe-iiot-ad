Overview

Watch the channel. Escalate only when it matters.

Contemporary IIoT deployments remain anchored to RSA/ECC, which face existential polynomial-time vulnerability under Shor's algorithm once a Cryptographically Relevant Quantum Computer (CRQC) exists — including retroactively, via "Harvest Now, Decrypt Later" interception happening today. Statically running a hardened post-quantum profile at all times is prohibitively expensive on Cortex-M4-class edge hardware. Q-Safe IIoT-AD instead monitors physical-layer QKD telemetry with a lightweight GRU and escalates crypto strength only on real evidence of interception.

Field Link

The same pipeline, protecting a link between real devices.

Everything above runs the framework against generated telemetry. The Field Link runs it against two phones. A phone becomes an industrial edge node and streams real sensor data across a link secured by BIKE-L1 or HQC-128; a second phone or a smartwatch receives and decrypts it. When the quantum channel shows evidence of interception, the link re-keys under the hardened profile mid-conversation — and the session key visibly changes on both screens, because a real KEM handshake just ran.

The adversary controls set eve_intercept_prob on the actual BB84 simulation. The QBER rises because of simulated quantum mechanics, not because a number was typed into a chart.

Fleet View

One device escalating is normal. Several, in sync, isn't.

Runs several devices side by side through the exact same real pipeline, tags each round with an attack-type classifier (eavesdrop / jamming / pns), and correlates across devices — distinguishing a coordinated, fleet-wide campaign from ordinary, unrelated per-device noise.

Deploy

Run it yourself

Docker

docker build -t qsafe-iiot-ad-web -f web/Dockerfile .
docker run --rm -p 8000:8000 qsafe-iiot-ad-web
# open http://localhost:8000

Local Python

pip install -r web/requirements.txt
bash scripts/setup_liboqs.sh   # skip on native Windows without WSL —
                                # the app runs fine without it, using a
                                # clearly-labeled simulated KEM backend
uvicorn web.backend.app:app --reload --port 8000
# open http://localhost:8000 — do NOT open index.html as a file:// path
